# Who Wants to Be an HCI Millionaire?

An interactive, browser-based multiplayer quiz platform designed to make the content of **AVT810S (African Values & Theories in HCI)** engaging, accessible, and contextually grounded. Developed as part of the **NUST HCI Honours 2026** curriculum.

## Project Overview
Modelled after the classic *Who Wants to Be a Millionaire?* framework, this platform replaces standard trivia with **15 escalating, scenario-based questions** rooted in Afro-centric interactive design. The game tests core course concepts—including Ubuntu, Philosophical Sagacity, community protocols, and localized user well-being—using content-justified design dilemmas.

## Key Features
* **15-Question Escalating Ladder:** Context-driven questions covering real-world African community case studies (San, Ovawambo, Himba, Maasai).
* **4 Custom Lifelines:** *Ask the Class* (player poll), *50/50* (removes two wrong options), *Phone a Peer* (avatar elder hint), and *Course Notes* (curriculum citation text box).
* **Multiplayer Mode:** Real-time competitive lobby for up to 4 players with a shared live leaderboard.
* **Afro-Centric UI Design:** An authentic visual identity featuring earthy color palettes (terracotta, warm gold), geometric pattern motifs, and dynamic local backgrounds.
